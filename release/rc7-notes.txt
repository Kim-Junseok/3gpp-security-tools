Keep PDCP/SDAP settings shared between Transmit and Receive, and generate LTE/NR PDCP headers from COUNT.

- Both tabs now share all PDCP header values and generation settings, plus SDAP presence and manual Hex. Payload text remains separate.
- Automatic is the default PDCP header source. Select the actual LTE/NR format, SN length and D/C where applicable; the generated Hex updates from COUNT's low SN bits. HFN stays outside the header, while the security primitives still use the full 32-bit COUNT.
- LTE SRB supports 5-bit SN; LTE DRB supports 7/12/15/18-bit SN. LTE SLRB supports 16-bit SN with its actual 3-byte identity/type prefix supplied separately.
- NR SRB supports 12-bit SN; NR DRB supports 12/18-bit SN. SRB and SLRB do not have a D/C field.
- LTE DRB supports P for DL/18-bit SN and AILC for UL/12-bit SN. Inactive flag settings are retained without changing generated bytes.
- Manual Hex remains available and keeps its own value across automatic/manual switches. SDAP remains manual and is not overwritten when UL/DL or the format changes.
- Invalid automatic input clears both previews and blocks calculation. D/C=0 Control PDUs cannot use the automatic Data PDU protection pipeline.
- PDCP/SDAP headers remain outside payload input/output and Ciphering, while Integrity includes both headers when present. Exact bit/byte length displays are preserved.
