# 검증 기록

문서 profile: TECHNICAL_NOTE. 최종 검증 결과는 실행 후 이 문서에 반영한다.

공식 알고리즘 검증·자체 통합·GUI widget·Windows 배포 시험을 별도로 기록한다.
현재 개발 실행에서 공식 36/36과 자체 테스트 21개가 통과했다.
초기 AES Windows EXE에서는 공식 14/14와 GUI widget 15/15를 확인했다.
전체 legacy를 포함한 최종 Windows EXE 시험은 진행 중이다.

공식 검증의 고정 분모는 Cip1 5, Itg1 7, Cip2 6, Itg2 8, Cip3 5, Itg3 5의 합계 36이다.
Null 정의 기반 시험과 통합·GUI 시험은 공식 분모에 포함하지 않는다.

실제 지원 환경과 미검증 환경을 최종 실행 근거에 맞춰 갱신한다.
